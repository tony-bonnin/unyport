# UnyPort 0.60.8

- Adds a native SVG device icon set for PCs, laptops, servers, NAS devices, printers, phones, tablets, routers, switches, access points, cameras, televisions and IoT devices.
- Adds pastel, visually distinct colors for every device family.
- Integrates optional `device_type` rendering into the network topology while preserving existing neighbor-state icons when no type is known.
- Replaces the main topology host cloud with a modern rack-host icon whose color follows the configured UnyPort role branding.
- Refines the bridge icon and its coral color.
- Keeps the demo host's Font Awesome rendering unchanged while making the device set available to the demo topology.
