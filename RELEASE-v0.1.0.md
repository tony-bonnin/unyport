# UnyPort v0.1.0

First public release of UnyPort.

## Highlights

- Real-time sysadmin dashboard written in Go.
- Designed for Alpine Linux and Xen environments.
- Single binary, single port deployment model.
- Monitoring-first foundation for future orchestration features.

## Included in this release

- Live host metrics and operational dashboard views.
- Security-focused application baseline with OAuth, JWT, CSRF, CSP, and TLS support.
- Docker workflow for development and production-style build steps.
- Frontend assets and Xen-aware platform context.

## Release status

`v0.1.0` marks the first stable public milestone of the project.
